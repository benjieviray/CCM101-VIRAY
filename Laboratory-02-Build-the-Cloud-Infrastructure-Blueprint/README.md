# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding the main components of cloud infrastructure. The activity involves exploring cloud computing resources and documenting how these components support cloud-based applications and services.

## Objectives

The objectives of this activity are to understand the major components of cloud infrastructure, explore cloud resources, compare cloud service options, and improve technical documentation skills.

## Cloud Infrastructure Components

The major components explored in this laboratory include:

- Compute Resources
- Storage Resources
- Networking Resources
- Operating Systems

These components work together to provide the resources required to run cloud applications and services.
