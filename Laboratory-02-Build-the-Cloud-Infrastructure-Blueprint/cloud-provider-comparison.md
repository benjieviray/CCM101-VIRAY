<h2>Cloud Provider Comparison</h2>

| Infrastructure Component         | AWS        | Microsoft Azure                 | Google Cloud                |
| -------------------------------- | ---------- | ------------------------------- | --------------------------- |
| **Compute**                      | Amazon EC2 | Azure Virtual Machines          | Compute Engine              |
| **Storage**                      | Amazon S3  | Azure Blob Storage              | Cloud Storage               |
| **Networking**                   | Amazon VPC | Azure Virtual Network (VNet)    | Virtual Private Cloud (VPC) |
| **Identity & Access Management** | AWS IAM    | Microsoft Entra ID / Azure RBAC | Google Cloud IAM            |

<p>These services represent equivalent core infrastructure capabilities across the three providers. AWS IAM controls authentication and authorization for AWS resources, while Google Cloud IAM uses roles and permissions to control access. Azure also provides role-based access control and Microsoft Entra-based authentication for Azure resources and virtual machines.</p>

<h4>1. Which cloud provider offers the broadest range of services?</h4>

<p>AWS is generally recognized as having one of the broadest selections of cloud services. It provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and many other areas.</p>

<h4>2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?</h4>

<p>I would recommend Microsoft Azure because it works closely with Microsoft's existing products and technologies. Organizations already using Windows Server, Microsoft 365, Active Directory, and other Microsoft services can benefit from Azure's integration.</p>

<h4>3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?</h4>

<p>Google Cloud Platform is widely recognized for its strengths in artificial intelligence, machine learning, and Kubernetes. Google also created Kubernetes, which makes Google Cloud a strong option for organizations working heavily with containerized applications.</p>

<h4>4. What similarities did you observe among the three cloud providers?</h4>

<p>All three providers offer similar basic infrastructure services, including virtual computing, storage, networking, and identity and access management. Although the services have different names, they perform similar functions and allow organizations to build scalable cloud-based systems.</p>
