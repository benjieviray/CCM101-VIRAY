# Mission Reflection

During this laboratory activity, I learned more about the different components of cloud infrastructure and how they work together. For me, I think the compute resource is one of the most important components because it provides the processing power needed to run applications and services. Without enough computing resources, applications may become slow or may not work properly. I also learned how Linux supports cloud computing by providing a reliable environment for running servers and applications. Using the KillerCoda terminal, I was able to use different Linux commands to check the operating system, CPU, memory, storage, hostname, and network information. This helped me understand how a cloud server can be inspected and managed using the command line. I also realized that technical documentation is important before deploying infrastructure because it provides a clear record of the system and its configuration. Proper documentation can help engineers understand the infrastructure, troubleshoot problems, and make future changes more easily. During this activity, I learned new skills such as investigating a Linux server, identifying compute, storage, networking, and operating system resources, comparing the services of AWS, Microsoft Azure, and Google Cloud, and creating a simple cloud infrastructure diagram. I also improved my skills in writing Markdown documentation and organizing files in GitHub. After completing this mission, I believe my GitHub portfolio has become more organized and useful because it now contains my server investigation, documentation, screenshots, cloud provider comparison, and infrastructure diagram. Overall, this activity helped me better understand how cloud infrastructure works and gave me practical experience that I can use in future cloud computing projects.
