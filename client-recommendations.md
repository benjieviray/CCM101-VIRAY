# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because it offers a wide range of cloud services that can support a startup from its early stage to rapid growth. The company can begin with small and cost-efficient resources and increase its infrastructure as the number of users grows. AWS also provides scalable and managed services that can reduce the need for maintaining physical servers.

### Recommended Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- AWS Lambda

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate platform because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, making migration and identity management easier. The university can also use hybrid cloud solutions to connect its existing infrastructure with Azure.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure SQL Database
- Azure Virtual Network

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is recommended because it has strong capabilities in Artificial Intelligence, Machine Learning, and high-performance computing. The company can use specialized computing resources to train and run demanding AI and ML workloads. Google Cloud also provides Vertex AI for developing, training, and deploying machine learning models.

### Recommended Services

- Vertex AI
- Compute Engine
- Cloud GPUs
- Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because the company needs highly available infrastructure that can serve customers around the world. AWS provides scalable compute, load balancing, storage, and database services that can support large e-commerce workloads. Automatic scaling and global infrastructure can help the company handle increases in traffic while maintaining application availability.

### Recommended Services

- Amazon EC2
- Elastic Load Balancing
- Amazon S3
- Amazon RDS
- Amazon CloudFront

---

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad range of services, scalability, and flexible infrastructure for growing businesses. |
| Enterprise Organization | AWS | Extensive cloud services and strong scalability for large organizations. |
| Microsoft Environment | Microsoft Azure | Strong integration with Windows Server, Microsoft 365, and Microsoft identity technologies. |
| AI / Machine Learning | Google Cloud Platform | Strong AI and ML capabilities through services such as Vertex AI and specialized computing resources. |
| Kubernetes Deployment | Google Cloud Platform | Google Kubernetes Engine provides a managed Kubernetes environment. |
| Global Web Application | AWS | Global infrastructure, load balancing, and automatic scaling support worldwide applications. |
