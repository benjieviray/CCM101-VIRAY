# Reflection

## 1. What did you learn about the differences between AWS, Azure, and GCP?

I learned that AWS, Microsoft Azure, and Google Cloud Platform provide similar cloud computing services, but each platform has different strengths. AWS has a very broad range of services and is suitable for many types of organizations. Azure is strong in Microsoft technologies and hybrid cloud environments, while GCP is particularly strong in artificial intelligence, machine learning, data analytics, and Kubernetes.

## 2. Which cloud platform would you choose for your future career and why?

I would choose Microsoft Azure for my future career because it provides many services that are useful for IT professionals. Azure also has strong integration with Microsoft technologies, which are commonly used by businesses and organizations. Learning Azure can help me develop skills in virtual machines, databases, networking, cloud security, and other cloud technologies.

## 3. What was the most challenging part of this laboratory?

The most challenging part of this laboratory was understanding the different services offered by each cloud provider and identifying their equivalent services. I also had to investigate a Linux environment using KillerCoda and understand how its system resources could be migrated to a cloud platform. This helped me become more familiar with Linux commands and cloud computing concepts.

## 4. How can multi-cloud strategies benefit organizations?

A multi-cloud strategy allows organizations to use different cloud providers based on their specific requirements. For example, an organization can use AWS for scalable applications, Azure for Microsoft-based systems, and GCP for artificial intelligence or data analytics. Using multiple providers can also reduce dependence on a single cloud provider and provide more flexibility.

## 5. How will you apply what you learned in future projects?

I can apply what I learned by selecting cloud services based on the requirements of future IT projects. I can compare providers before deciding where to deploy applications, databases, or virtual machines. I also learned that understanding Linux and cloud infrastructure is important because many modern applications are hosted in cloud environments.
